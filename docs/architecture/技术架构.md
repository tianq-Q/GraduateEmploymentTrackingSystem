# 技术架构

## 技术栈
| 层级 | 技术 |
|------|------|
| 后端框架 | Spring Boot 3.x |
| ORM | MyBatis-Plus |
| 数据库 | MySQL 8.0 |
| 安全 | Spring Security + JWT |
| 前端框架 | Vue 3 + TypeScript + Vite |
| UI 组件 | Element Plus |
| 图表 | ECharts 5 |
| 状态管理 | Pinia |
| 路由 | Vue Router 4 |

## 分层架构 (DDD)
```
controller  →  application  →  domain  →  infrastructure
  (API)        (用例)         (领域)       (持久化/文件/安全)
```

## 代码组织
```
backend/src/main/java/com/college/employment/
├── EmploymentApplication.java      # 启动类
├── common/                         # 通用层 (Result, Exception, Util)
│   ├── api/                        # 统一响应体
│   ├── exception/                  # 异常处理
│   ├── enums/                      # 枚举
│   ├── log/                        # 日志切面
│   └── util/                       # 工具类
├── config/                         # 配置类
├── controller/                     # 控制器层 (Rest API)
├── application/                    # 应用服务层
│   ├── auth/                       # 认证用例
│   ├── basedata/                   # 基础数据用例
│   ├── employment/                 # 就业/审核用例
│   ├── dashboard/                  # 仪表板用例
│   ├── system/                     # 系统管理用例
│   └── dto/                        # 数据传输对象
├── domain/                         # 领域层
│   ├── model/                      # 领域实体
│   ├── repository/                 # 仓储接口
│   ├── policy/                     # 业务策略
│   └── port/                       # 外部依赖端口
└── infrastructure/                 # 基础设施层
    ├── mapper/                     # MyBatis Mapper
    ├── file/                       # 文件存储实现
    ├── audit/                      # 审计实现
    ├── notify/                     # 通知实现
    └── security/                   # 安全实现
```
