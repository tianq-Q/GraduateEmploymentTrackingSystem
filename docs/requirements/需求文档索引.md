# 需求文档

## 功能需求 (FR)
- **FR-01** 用户认证与权限管理
- **FR-02** 基础数据管理 (院系/专业/班级/毕业生/教师)
- **FR-03** 就业信息采集与审核 (学生填报 + 教师代录 + 二级审核)
- **FR-04** 数据仪表板 (就业率/去向/院系对比/行业分布)

## 角色与权限
| 角色 | 权限范围 |
|------|---------|
| SYSTEM_ADMIN | 系统管理员，全部功能 + 用户与日志管理 |
| COLLEGE_ADMIN | 校级管理员，基础数据管理 + 终审权限 |
| TEACHER | 就业教师，本院系初审 + 代录 + 看板 |
| GRADUATE | 毕业生，提交就业信息 + 查看状态 |
